# Spec to Part

An in-browser, AI-native CAD production demo. Describe a simple mechanical part in plain English and receive a parametric 3D preview, STL and STEP files, CadQuery source, and a manufacturing-readiness summary.

The GitHub Pages build runs entirely in the browser, with no API keys or backend required.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
